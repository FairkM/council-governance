# Council Governance Contract

A governance contract enabling representative decision-making through an
elected or appointed council of members.

## Key Functions
- `add-member` — Appoint a new council member
- `remove-member` — Revoke council membership
- `create-proposal` — Submit a decision for council review
- `approve-proposal` — Cast a council vote
- `execute-proposal` — Finalize and execute approved actions

Designed for DAOs and protocols requiring fast, accountable governance through
a smaller trusted body.
